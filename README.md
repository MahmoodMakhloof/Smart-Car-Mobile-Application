# 🚘 Smart Car Application – IoT System

A real-time, Flutter-based smart car management system built with clean architecture and modern protocols.  
Sponsored by **Valeo**, this project delivers advanced features like remote vehicle control, live tracking, and smart alerts — all accessible via a seamless mobile app.

---

## 🛠️ Tools & Technologies

- **Architecture:** MVVM, BLoC
- **Mobile:** Flutter (iOS & Android)
- **Communication:** RESTful APIs, MQTT (for real-time control), Socket.IO
- **Backend:** Node.js + MongoDB
- **Others:** Push Notifications, Secure Authentication

---

## 🚀 Features

- 🔑 **Remote Access**: Start/stop motor, lock/unlock doors, open trunk, control AC — all remotely.
- 📍 **Live Car Tracking**: Real-time speed, temperature, and location monitoring.
- 👥 **Car Sharing**: Use virtual keys to give temporary or permanent access to others.
- 🛑 **Speed Limiting**: Set and enforce custom speed limits per user or vehicle.
- 🚨 **Smart Admin Alerts**: Receive alerts for over-speeding, unauthorized access, and firmware updates.
- 🔒 **Security & Access Control**: Role-based access with secure MQTT & REST APIs.
- 📡 **OTA Firmware Integration**: Receive alerts when new firmware is available.
- 📊 **Dashboard-ready Backend**: Built for integration with admin panels and analytics systems.
